# RWB Shipment Forecasting

Проект команды для кейс-чемпионата Т1, 2026. Кейс RWB — **«Отгрузки без простоев»**.

## Задача

Прогнозирование объёмов отгрузок по логистическим маршрутам для планирования загрузки складов в пиковые периоды.

Для каждой пары `route_id` и `timestamp` необходимо предсказать `target_1h` — объём товаров, отгруженных по маршруту за последний час.

## Данные

- Train: Parquet с историей, статусами обработки товаров и целевой переменной.
- Test: Parquet без статусов и целевой переменной.

## Статус

Начальный этап: анализ данных и разработка модели предстоят.
