# Объём каждого маршрута за окно прогноза

Модель оценивает сумму семи будущих значений `target_1h` для каждого маршрута, с 11:30 по 14:30. Это сумма оцениваемых часовых окон, которые перекрываются. Она используется для распределения прогноза между маршрутами.

Каждую субботу в 10:30 модель LightGBM обучается на доступных утренних наблюдениях за предшествующие 42 дня. Для обучения нужны все будущие значения конкретного исторического окна. У финальной модели последняя обучающая метка относится к 31 октября 15:30. В течение недели параметры деревьев зафиксированы, а признаки обновляются до момента каждого прогноза.

За основу берётся [CSV с поправкой по потокам](stage-flow.md). Его прогноз на 11:00 сохраняется. Для следующих семи горизонтов модель смешивает поровну две оценки общего объёма каждого маршрута и согласует результат с исходными сетевыми суммами. После этого сумма каждого столбца совпадает с прогнозом сети для данного горизонта, а сумма каждой строки — с обновлённой оценкой маршрута в пределах численной точности.

На 14 датах разработки средний score снизился с **0,326326** до **0,326236**. Модель выиграла на 9 датах. Средняя разница за первую неделю составила +0,000010, за вторую −0,000190. [Сравнение по отдельным датам](../results/weekly_route_window_l1/development/folds.csv).

Для воспроизведения сначала соберите `submissions/h1_centered_stage_flow.csv`. Затем выполните команду из корня проекта.

```bash
python scripts/apply_weekly_route_window.py \
  --train data/raw/train_solo_track.parquet --test data/raw/test_solo_track.parquet \
  --anchor submissions/h1_centered_stage_flow.csv \
  --output submissions/weekly_route_window_l1_reproduced.csv
```

Итоговый CSV содержит 8000 строк. Его SHA-256 — `1aafe9a1de5393e3ff653e6e87e03756eaa879f3fc578c0ec1bc0f2bd498a95f`. Рядом сохраняются модель LightGBM, её 1000 прогнозов по маршрутам и метаданные расчёта.
