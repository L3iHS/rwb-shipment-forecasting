# Поправка по потоку товаров между этапами

Для каждого маршрута известны количества товаров, прошедших три этапа обработки в последние полчаса. Поправка оценивает, насколько текущая разница накопленных входов и выходов между соседними этапами отклонилась от своего среднего за последние сутки. Абсолютное число товаров в очереди из этих данных неизвестно.

На последних 14 днях обучаются две модели Ridge на одинаковых утренних отсечках. Первая использует историю отгрузок, статусов и календарь. Вторая получает ещё шесть признаков изменения потоков. Разница между их прогнозами корректирует [базовый прогноз с уточнением первого часа](full-known-h1.md). Сумма по маршрутам на каждом горизонте сохраняется. Для первого часа поправка затрагивает только оставшуюся прогнозируемую часть после учёта уже прошедшего получаса.

На 14 октябрьских датах средний score снизился с **0,326405** до **0,326326**, выигрыш на 9 датах. В первой неделе средняя разница составила −0,000212, во второй +0,000055. [Результаты по датам](../results/h1_centered_stage_flow/development/folds.csv).

Сначала воспроизведите `v3_mlp_full_known_h1.csv`, затем выполните команду из корня проекта:

```bash
python scripts/apply_stage_flow.py \
  --train data/raw/train_solo_track.parquet --test data/raw/test_solo_track.parquet \
  --anchor submissions/v3_mlp_full_known_h1.csv \
  --output submissions/h1_centered_stage_flow_reproduced.csv
```

Для проверенного базового CSV с SHA-256 `27a47563cf8a9aed162b0cd9666d633af49bbfab525ef2b0d820270bfc0ca209` новый файл содержит 8000 строк, SHA-256 `703febb6cd1c6a204f32ef5d71fe85ba87cbe978818f26e4dba2a8ad7d94b5c9`. Перед запуском выберите свободное имя выходного файла.
