# Взвешенный бустинг и перераспределение объёма

`objective_scale1_mass50` добавляет веса обучающих строк к нормализованному HGB: вес пропорционален среднему объёму маршрута за 48 предыдущих получасовых точек, с минимумом 1000. Средний вес равен единице. Все масштабы считаются отдельно по доступной истории каждого источника.

Первый горизонт сохраняет прогноз latent Ridge. Для горизонтов 2–8 половина прогноза берётся из взвешенного HGB, половина — из долей latent Ridge, приведённых к сумме взвешенного HGB. Поэтому итог сохраняет именно новые суммы взвешенного бустинга. Параметр смешивания фиксирован: 0,5.

## Локальная проверка

14 ежедневных окон 18–31 октября 2025 года, начало прогноза — 10:30, горизонт — восемь получасовых точек. Средний score — арифметическое среднее `WAPE + abs(relative bias)` по окнам.

| Модель | Средний score | WAPE | Абсолютный bias | Худшее окно |
|---|---:|---:|---:|---:|
| Предыдущий гибрид | 0,333307 | 0,317785 | 0,015522 | 0,363841 |
| `latent_mass_blend50` | 0,332570 | 0,317049 | 0,015522 | 0,362314 |
| Только взвешенный бустинг с latent H1 | 0,332886 | 0,317264 | 0,015622 | 0,364285 |
| `objective_scale1_mass50` | **0,332322** | **0,316700** | 0,015622 | 0,362505 |

Улучшение относительно `latent_mass_blend50` — 0,000249 в среднем, победы на 7 из 14 окон. Bias и худшее окно немного ухудшились. Эти даты уже использовались для разработки; новый отложенный контроль ещё не выполнен. Результат платформы для этого CSV пока неизвестен. Лучший подтверждённый публичный score остаётся 0,330 у `latent_mass_blend50` по скриншоту участника.

## Воспроизведение

```bash
python scripts/make_candidate_submission.py --config configs/objective_scale1_mass50.json
```

Команда создаёт `submissions/objective_scale1_mass50.csv` и метаданные после обучения на доступном train. CSV содержит 8000 строк с колонками `id,y_pred`; отправка на платформу выполняется отдельно. Существующие файлы не перезаписываются; для повторного запуска задайте новый `--output`.
