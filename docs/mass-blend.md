# Перераспределение прогноза с сохранением общего объёма

`latent_mass_blend50` сохраняет первый горизонт `latent_ridge_h1_hybrid`. Для горизонтов 2–8 получасовой Ridge задаёт альтернативное распределение объёма между маршрутами. Его прогнозы нормируются на предсказанную сумму исходного гибрида для каждого горизонта, затем смешиваются с ним поровну. Неизвестные фактические суммы не используются.

Общая сумма и штраф за bias сохраняются с точностью вычислений. Изменяется WAPE. При нулевой сумме альтернативного прогноза используется исходный прогноз.

| Оценка | Исходный гибрид | Перераспределение 50% |
|---|---:|---:|
| Средний локальный score, 18–31.10.2025 | 0,333307 | **0,332570** |
| Средний WAPE на этих же 14 окнах | 0,317785 | **0,317049** |
| Средний абсолютный bias | 0,015522 | 0,015522 |
| Public leaderboard, скриншоты участника 07.11.2026 | 0,331 | **0,330** |

Локально выиграны 13 из 14 окон. Вес 0,5 выбран среди 0,25 / 0,5 / 1,0 на шести окнах отбора, после чего только он проверен на всех 14 окнах. Эти шесть входят в набор из 14; последняя оценка является результатом разработки. На семи дополнительных окнах 4–10 октября средний score — **0,343437** против **0,343906** у исходного гибрида, выиграны шесть из семи окон. [Контроль и ограничения](mae-shares.md#контроль-на-семи-дополнительных-окнах). Публичные оценки округлены интерфейсом платформы, результат приватного теста неизвестен.

Проверки разработки используют ранее рассчитанные причинные прогнозы компонентов с проверкой исходников, ключей, фактических значений и границ обучения. Рабочий predictor обучает оба компонента заново по переданной истории. Подробные прогнозы и исследовательские материалы хранятся локально; агрегированные результаты — в [results/mass_blend/development](../results/mass_blend/development/).

## Воспроизведение

```bash
python scripts/run_comparison.py --config configs/latent_mass_blend50.json --split research --output .local/reproduce/mass_blend
python scripts/make_candidate_submission.py --config configs/latent_mass_blend50.json
python -m pytest -q
```
