# Смесь v3 и недельного прогноза

В новой v3 сокомандника дневные профили маршрутов за 28 дней сглаживаются SVD ранга 12. Они входят в признаки и сезонную базу бустингов. В ансамбле фиксированы доли XGBoost, Huber и Tweedie — 0,8 / 0,1 / 0,1. По проверочным прогнозам подбирается один общий множитель. [Исходный код и прогнозы](https://github.com/L3iHS/rwb-shipment-forecasting/tree/3b7394a0afeab51ef7a819164c742bf5405c387d).

Новый вариант усредняет объёмы v3 и нашего недельного бустинга с весами 0,5 / 0,5. Сопоставление выполняется по ID. На 14 датах 18–31 октября средний score составляет **0,324396** против **0,324858** у исходной v3. На первой неделе смесь получила 0,324719 против 0,324411, на второй — 0,324073 против 0,325305. [Все даты](../results/ensemble_v3_weekly50/development_folds.csv).

При подборе множителя v3 только на первой неделе оценка на второй составляет 0,325305 у v3 и 0,324073 у смеси. У нашего недельного прогноза — 0,324413. Даты обеих недель уже использовались в разработке. [Хронологическая проверка](../results/ensemble_v3_weekly50/forward_folds.csv).

## Контроль на другом периоде

После выбора смеси с фиксированными долями 0,5 / 0,5 её проверили на семи датах с 27 сентября по 3 октября. Все компоненты обучались заново. Единственный множитель v3 — **1,0175** — подобран только по проверочным прогнозам за 13–26 сентября. Октябрьские коэффициенты на контроль не переносились.

| Модель | Средний score | WAPE | Штраф за смещение |
|---|---:|---:|---:|
| Исходная v3 | 0,339181 | 0,316592 | 0,022589 |
| Недельная модель | 0,337069 | 0,316322 | 0,020748 |
| Смесь v3 и недельной модели | 0,337244 | 0,315782 | 0,021462 |

Смесь улучшила среднее исходной v3 на **0,001936** и выиграла у неё на четырёх датах из семи. Недельная модель на этом периоде оказалась чуть сильнее смеси. Поэтому результат подтверждает выигрыш относительно v3 по среднему, но не превосходство над каждым компонентом на всех периодах. [Результаты по датам](../results/ensemble_v3_weekly50/control/folds.csv) · [Методика и параметры](../results/ensemble_v3_weekly50/control/metadata.json).

Это ранняя историческая проверка: её метрики не использовались при выборе смеси, а сам период входит в историю обучения более поздних октябрьских моделей. Предикторы получали только данные до своей точки прогноза; метки обучения не выходили за неё. Недельному бустингу здесь доступны 32 утренние смены, при сборке конкурсного CSV — 42. Контрольный XGBoost обучен на CPU с четырьмя потоками, исходный конкурсный прогноз v3 — на CUDA. Публичная оценка смеси пока неизвестна.

## Сборка CSV

Для работы в Jupyter доступен [ноутбук решения](../notebooks/ensemble_v3_weekly50.ipynb). Его входы включены в Git; он пересчитывает метрики из сохранённых проверочных прогнозов и собирает тот же CSV. Ссылки на полное обучение компонентов находятся в конце ноутбука.

Сохраните [исходный файл v3](https://github.com/L3iHS/rwb-shipment-forecasting/blob/3b7394a0afeab51ef7a819164c742bf5405c387d/submissions/ensemble_v3.csv) как `submissions/teammate_ensemble_v3.csv`. Затем выполните ту же команду усреднения с новым входом и выходом.

```bash
python scripts/make_v2_weekly_blend.py \
  --peer-csv submissions/teammate_ensemble_v3.csv \
  --weekly-csv submissions/weekly_v3_latent_half_shares.csv \
  --test data/raw/test_solo_track.parquet \
  --output submissions/ensemble_v3_weekly50.csv
```

Проверенный CSV содержит 8000 строк. Повторная сборка дала побайтно тот же файл. SHA-256 — `e24f49a8cf0c748db20c92392f64c8735ed7857a00b9501c0fefd41bcc3ee484`. На платформу файл автоматически не отправлялся.
