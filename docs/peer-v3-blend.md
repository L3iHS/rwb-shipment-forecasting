# Смесь v3 и недельного прогноза

В новой v3 сокомандника дневные профили маршрутов за 28 дней сглаживаются SVD ранга 12. Они входят в признаки и сезонную базу бустингов. В ансамбле фиксированы доли XGBoost, Huber и Tweedie — 0,8 / 0,1 / 0,1. По проверочным прогнозам подбирается один общий множитель. [Исходный код и прогнозы](https://github.com/L3iHS/rwb-shipment-forecasting/tree/3b7394a0afeab51ef7a819164c742bf5405c387d).

Новый вариант усредняет объёмы v3 и нашего недельного бустинга с весами 0,5 / 0,5. Сопоставление выполняется по ID. На 14 датах 18–31 октября средний score составляет **0,324396** против **0,324858** у исходной v3. На первой неделе смесь получила 0,324719 против 0,324411, на второй — 0,324073 против 0,325305. [Все даты](../results/ensemble_v3_weekly50/development_folds.csv).

При подборе множителя v3 только на первой неделе оценка на второй составляет 0,325305 у v3 и 0,324073 у смеси. У нашего недельного прогноза — 0,324413. Даты обеих недель уже использовались в разработке. [Хронологическая проверка](../results/ensemble_v3_weekly50/forward_folds.csv).

## Сборка CSV

Сохраните исходный файл v3 как `submissions/teammate_ensemble_v3.csv`. Затем выполните ту же команду усреднения с новым входом и выходом.

```bash
python scripts/make_v2_weekly_blend.py \
  --peer-csv submissions/teammate_ensemble_v3.csv \
  --weekly-csv submissions/weekly_v3_latent_half_shares.csv \
  --test data/raw/test_solo_track.parquet \
  --output submissions/ensemble_v3_weekly50.csv
```

Проверенный CSV содержит 8000 строк. SHA-256 — `e24f49a8cf0c748db20c92392f64c8735ed7857a00b9501c0fefd41bcc3ee484`. Публичная оценка нового файла пока неизвестна.
