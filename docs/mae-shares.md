# Доли маршрутов из модели MAE

`mae_share_mass25` сохраняет 75% прогноза `objective_scale1_mass50`, а 25% берёт из модели, обученной с абсолютной ошибкой и весами исходного объёма. Для горизонтов 2–8 прогноз MAE приводится к сумме текущего взвешенного прогноза. Первый горизонт остаётся прежним. Таким образом, меняется распределение между маршрутами, а общая предсказанная сумма каждого горизонта сохраняется.

## Локальная проверка

На шести окнах сравнивались фиксированные доли 0,25 / 0,5 / 1. Только выбранная доля 0,25 проверена на всех 14 ежедневных окнах 18–31 октября 2025 года, 10:30.

| Модель | Средний score | WAPE | Абсолютный bias | Худшее окно |
|---|---:|---:|---:|---:|
| `latent_mass_blend50` | 0,332570 | 0,317049 | 0,015522 | 0,362314 |
| `objective_scale1_mass50` | 0,332322 | 0,316700 | 0,015622 | 0,362505 |
| `mae_share_mass25` | **0,332149** | **0,316527** | 0,015622 | 0,362506 |

Выигрыш относительно взвешенного варианта — 0,000173, победы на 11 из 14 окон. Улучшение небольшое; худшее окно практически не изменилось. Все даты уже использовались для разработки. Публичный score неизвестен. Контрольный результат приведён ниже.

## Контроль на семи дополнительных окнах

До расчёта были зафиксированы один новый финалист и два прежних ориентира. На каждом из семи окон 4–10 октября 2025 года, 10:30, все компоненты обучены заново только по доступной истории.

| Модель | Средний score | WAPE | Абсолютный bias | Худшее окно |
|---|---:|---:|---:|---:|
| `latent_ridge_h1_hybrid` | 0,343906 | 0,323459 | 0,020447 | 0,362732 |
| `latent_mass_blend50` | **0,343437** | 0,322990 | **0,020447** | 0,362221 |
| `mae_share_mass25` | 0,343478 | **0,322737** | 0,020741 | **0,360798** |

Новый вариант выиграл у `latent_mass_blend50` на трёх из семи окон, но проиграл по среднему score на 0,000041. Условие улучшения относительно обоих ориентиров не выполнено: вариант остаётся экспериментальным. Меньший WAPE не компенсировал увеличение штрафа за bias. Лучший подтверждённый публичный результат по-прежнему принадлежит `latent_mass_blend50` — 0,330.

Это дополнительные исторические окна раньше периода разработки, а не независимый будущий тест. Конфигурация финалиста выбрана до расчёта контроля; теперь эти даты считаются использованными. Резерв 27 сентября — 3 октября не открыт, порог 0,32 не достигнут. Исходный конфиг создания CSV сохранён без изменений; его отметка о статусе отражает момент фиксации, актуальный итог — здесь.

## Воспроизведение

```bash
python scripts/make_candidate_submission.py --config configs/mae_share_mass25.json
```

Создаётся локальный `submissions/mae_share_mass25.csv`, 8000 строк `id,y_pred`, и файл метаданных. Компоненты обучаются заново на известных наблюдениях train; прогноз MAE для первого горизонта вычисляется, но не участвует в композиции. Команда не отправляет результат на платформу. Для повторного запуска используйте новый путь `--output`.
