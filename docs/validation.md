# Временная валидация простых прогнозов и Ridge

## Протокол

Семь начал прогноза: **25–31 октября 2025 года, ежедневно в 10:30**. Час совпадает с началом реального четырёхчасового прогноза после последнего факта train. Для каждой даты прогнозируются следующие восемь получасовых точек по всем 1000 маршрутам — 8000 точек на окно, 56 000 на модель за весь прогон.

Предикторы получают только срез истории до начала прогноза включительно. Для каждого окна Ridge обучается заново; все его обучающие таргеты заканчиваются не позже начала этого окна. Факты оценочного интервала используются только после получения прогнозов, для расчёта метрик. Препроцессинг Ridge обучается только на его fit-части.

Первичный критерий сравнения — арифметическое среднее официального `WAPE + |Relative Bias|` по семи окнам. Стандартное отклонение показывает разброс между окнами, а не доверительный интервал. Окна используют пересекающуюся обучающую историю и не являются независимыми экспериментами.

Pooled score по всем 56 000 точкам сохранён как дополнительный показатель. Он не заменяет среднее score: разнонаправленный bias разных дней при объединении может взаимно компенсироваться.

## Модели

| Имя | Правило |
|---|---|
| `last_value` | Последний известный `target_1h` для всех восьми точек |
| `mean_last_3h` | Среднее шести последних известных значений таргета |
| `seasonal_day` | Значения соответствующих времён предыдущего дня |
| `seasonal_week` | Значения соответствующих времён предыдущей недели |
| `ridge_status` | Ridge по шести статусам на исходный момент и one-hot категории маршрута; восемь выходов |

Ridge сохраняет набор признаков организаторского baseline. Используется `StandardScaler` для статусов, `OneHotEncoder` для маршрута, `alpha=4`, численный solver `lsqr`, `tol=1e-6`. Отрицательные предсказания обрезаются до нуля. Изменение solver относительно автоматического выбора оригинального notebook сделано явно; основной метод остаётся линейной Ridge-регрессией.

Обучающие source timestamps берутся из последних 14 дней до последнего допустимого source включительно. Последний source находится за четыре часа до начала проверочного прогноза: его восьмой таргет уже известен в момент отсечения. Получается 673 source-точки × 1000 маршрутов = 673 000 обучающих строк на окно. Сэмплирование не применяется. Параметры не подбирались по этим результатам.

Документация методов: [Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html), [временное разделение](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html). Разделение реализовано по общим временам всех маршрутов и по доступности будущих таргетов, а не по случайным строкам.

Прогон выполнен на исходном train; точные версии библиотек, SHA-256 датасета и исходного кода находятся в [metadata.json](../results/baselines/metadata.json).

Ridge улучшает средний score относительно лучшего простого ориентира на **19,59%** и выигрывает на каждом из семи окон. Для его объединённых прогнозов WAPE равен 0,331611, signed bias — −0,024270: суммарный прогноз примерно на 2,43% ниже суммы фактов.

Качество Ridge по отдельным горизонтам ухудшается от среднего score 0,337488 на +30 минут до 0,401638 на +4 часа. Это описательный результат данного набора окон, а не доказательство причин ошибок.

## Воспроизведение

Из корня репозитория после установки `requirements.txt`:

```bash
python scripts/run_backtest.py --origin-count 7 --origin-time 10:30 --train-days 14 --alpha 4.0
python scripts/plot_backtest.py
python -m pytest -q --cov=rwb_forecasting --cov-branch --cov-report=term-missing
```

По умолчанию подробные прогнозы, метрики, границы fit-частей, версии и график сохраняются в исключённую из Git `.local/runs/temporal_baselines/`. В `results/baselines/` включены только проверенные агрегированные результаты этого прогона и их происхождение.

## Ограничения

- Проверены семь недавних дат только с началом в 10:30. Результат нельзя автоматически переносить на все часы или другие периоды.
- Все пять моделей сравниваются на одинаковых точках. Новые модели следует сравнивать с ними в том же протоколе и отдельно проверять на дополнительных нетронутых окнах.
- Здесь нет новых признаков истории таргета для Ridge, настройки гиперпараметров, калибровки или ансамблей.
- Реальный test не оценивался: его факты неизвестны. CSV на платформу не отправлялся.
- Скользящие часовые значения `target_1h` перекрываются; их сумма по времени не является числом уникальных отгрузок за этот период.
