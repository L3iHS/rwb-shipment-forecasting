# Уточнение уже наблюдаемой части первого часа

В 11:00 модель прогнозирует объём за 10:00–11:00. При отсечке 10:30 первая половина этого часа уже прошла. Её объём не дан отдельным столбцом, но его можно ограничить по предыдущим часовым суммам: каждую соседнюю пару таких сумм связывает общий получасовой интервал.

[Базовая модель V3/MLP](latent_mlp.md) уже учитывает это перекрытие, оценивая известную часть из последних 16 сырых наблюдений. Новый вариант заменяет только это слагаемое. При восстановлении по полной истории допускается округление каждой исходной часовой суммы на ±0,5. Допустимый интервал для последнего получаса вычисляется последовательно, от первого наблюдения до момента прогноза. Его середина — оценка, а не непосредственно наблюдаемое значение.

Первый прогноз равен `max(старый H1 − старая оценка + новая оценка, 0)`. Сумма на первом горизонте может меняться. Прогнозы с 11:30 до 14:30 побайтно совпадают с исходным CSV.

| 14 дат разработки, 18–31 октября | WAPE | Средний штраф за смещение | Score |
|---|---:|---:|---:|
| V3/MLP | 0,315679 | 0,011753 | 0,327433 |
| V3/MLP с уточнением первого часа | 0,315037 | 0,011368 | **0,326405** |

Новый вариант лучше на 11 из 14 дат. [Метрики по отдельным датам](../results/v3_mlp_full_known_h1/development/folds.csv). Это локальный результат на датах разработки.

Для сборки нужен базовый `submissions/v3_totals_mlp_shares50.csv`. Команда проверяет его SHA-256, использует ключи из test и пишет новый локальный файл:

```bash
python scripts/apply_known_h1.py --output submissions/v3_mlp_full_known_h1_reproduced.csv
```

Проверенный результат содержит 8000 строк; SHA-256 — `27a47563cf8a9aed162b0cd9666d633af49bbfab525ef2b0d820270bfc0ca209`. Для воспроизведения временного сравнения добавьте `--include-known-h1` к [команде backtest](latent_mlp.md).

## Проверка на отдельной неделе

На семи датах с 30 августа по 5 сентября средний score модели с уточнением первого часа — **0,330071**, у исходной V3/MLP — **0,330840**. Поправка выиграла у неё на 4 из 7 дат. Для V3, MAE25 и mass50 средние значения составили 0,333036, 0,328463 и 0,329052. На этой ранней неделе для V3 было доступно от 4 до 10 утренних дней обучения. При сборке финального CSV их было 42.
