# Прогноз по маршрутам на основе получасовых отгрузок

Модель пересчитывает долю каждого маршрута в общем объёме. Базовый прогноз объёма для каждого из восьми горизонтов задаёт [модель с признаками движения между этапами склада](stage-flow.md).

LightGBM обучается по субботам в 10:30 на данных последних 42 утренних смен. Для каждого обучающего примера целиком известны следующие восемь получасов. Непересекающиеся получасовые объёмы восстанавливаются из часовых наблюдений. Регрессор Tweedie с 600 деревьями предсказывает эти объёмы, затем соседние прогнозы складываются для получения часового значения. Признаки и веса основаны на [реализации V3 участника Владо](v3_tweedie_h1_600.md). Каждый день модель получает данные, доступные к текущим 10:30.

По каждому горизонту итоговая доля маршрута равна среднему его долей в двух прогнозах. На первом горизонте уже прошедший получас учитывается отдельно, и модель перераспределяет только прогноз оставшейся части часа. Суммарный объём каждого горизонта совпадает с базовым.

## Качество

На 14 датах разработки с 18 по 31 октября средний score составил **0,326069**. У базовой модели с признаками движения он составил 0,326326. Выигрыш пришёлся на WAPE, так как общий объём сохранился. У двух моделей с публичной оценкой 0,328 на этих же датах было 0,326405 и 0,327433. Новый прогноз выиграл у них на 11 и 12 датах соответственно. Из двух вариантов недельного бустинга выбрали один по первым семи датам. Эти даты входят в среднее за 14 дней. ## Сборка CSV

Установите зависимости проекта и подготовьте базовый файл по [инструкции для модели движения между этапами](stage-flow.md). Команда из корня репозитория выполнит обучение и создаст файл с 8000 парами `id,y_pred`.

```sh
.venv/bin/python scripts/run_weekly_latent.py \
  --config configs/weekly_v3_latent_half_shares.json \
  --train data/raw/train_solo_track.parquet \
  --test data/raw/test_solo_track.parquet \
  --anchor submissions/h1_centered_stage_flow.csv \
  --output submissions/weekly_latent_reproduced.csv
```

Параметр `--work-dir` задаёт каталог для временной многогигабайтной матрицы обучения. Рядом с CSV сохраняются дерево моделей LightGBM в `.model.txt`, границы обучения в `.fit.json` и контрольные суммы в `.metadata.json`. Для повторного прогноза из сохранённой модели укажите новое имя выходного файла и передайте `--model-in` и `--fit-audit-in` с путями к соответствующим файлам.

У проверенного файла `submissions/weekly_v3_latent_half_shares.csv` SHA-256 `2d870aa472552265864b43fe13bb6c683b5d879cc4d887be568dc4741ea046a1`. Повторный прогноз из сохранённой модели дал побайтно тот же CSV.
