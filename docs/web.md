# Веб-пульт диспетчера

Рабочий интерфейс — React 18 + TypeScript + Vite, Tailwind 4, Motion, Lucide. Графики реализованы в SVG. Шрифты Sofia Sans и Martian Mono включаются локально через пакеты Fontsource. Оформление и поведение — [design.md](design.md).

## Запуск

```sh
cd frontend
npm ci
npm run dev
```

Для сборки — `npm run build`; результат в `frontend/dist`. Веб-пульт читает сохранённый `frontend/public/board.json`. Обновление сервера описано в [deployment.md](deployment.md).

## Данные и расчёты

Снимок содержит момент `now`, получасовой шаг `step_min`, параметры сценария `model`, суммарные ряды `network` и маршруты `routes`. По маршруту: вместимость `cap`, груз у ворот `bl` в кузовах, машины `way`/`dock`, история `h`, прогнозы `p10`/`p50`/`p90`, накопленный приход `c50`/`c90` и поток правила `cr`.

`plan.ts` пересчитывает время вызова при изменении подачи и осторожности. `tools.ts` и `brief.ts` строят сводку и локальные ответы из того же снимка. Это сохранённый формат интерфейса участника, а не подключение нового общего ML snapshot; различия зафиксированы в [integration.md](integration.md). Команды `pipeline.py export` в текущем pipeline нет.

## Отметка вызова

«Вызвал» или Enter по выбранному срочному маршруту добавляет машину в локальный журнал. Каждый вызов увеличивает число машин в пути и пересчитывает очередь. Следующий маршрут выбирается автоматически, если отмеченный ушёл из фильтра. Последний вызов можно отменить в строке прогресса, вызов конкретного маршрута — в карточке.

Журнал сохраняется в `localStorage` под ключом `calls:<now>` и действует только в данном браузере. Новый момент снимка начинает отдельный журнал. Это отметка диспетчера, без отправки реальной заявки или общей серверной синхронизации.

## Ассистент и граница демо

На `rwb.ochev.net` публикуется статический пульт со снимком. `/api/*` отключён; ассистент отвечает локально на типовые вопросы о маршруте, грузе без машины, подаче и пике. Он объясняет правило и может открыть маршрут, поменять фильтр или сценарий. Экран для жюри исключён.

В исходниках сохранён отдельный FastAPI-прототип `backend/`; его запуск не входит в публикацию фронтенда. Фронтенд подготовлен к `POST /api/agent` с историей вопросов и контекстом `view`: `tab: shift`, `route`, `lead_h`, `risk`, `called`. Перед подключением LLM необходимо согласовать поддержку локального журнала вызовов на сервере, общий snapshot и лимиты провайдера. Ключи в браузер и статическую сборку не передаются.
