# Прогноз V3 с долями маршрутов из MLP

Модель [V3](v3_tweedie_h1_600.md) задаёт общий объём на каждый из восьми горизонтов. На первом горизонте сохраняется и её прогноз для каждого маршрута. На горизонтах 2–8 часть объёма перераспределяется между маршрутами по прогнозам нейросети и [MAE25](mae-shares.md). Это позволяет улучшить WAPE без изменения штрафа за суммарное смещение.

Нейросеть использует 14 дней получасовых наблюдений. Для каждого момента обучения все восемь целевых значений уже известны к моменту прогноза. Модель восстанавливает скрытые получасовые отгрузки и складывает соседние получасовые прогнозы для получения часового. Числовые признаки стандартизируются только на обучающей выборке. К ним добавляется обучаемое представление маршрута. Архитектура, нормализация и параметры обучения зафиксированы в [конфигурации](../configs/v3_totals_mlp_shares50.json).

Сначала половина долей MAE25 заменяется долями исходной MLP, затем половина долей V3 заменяется полученными долями. Оба шага сохраняют предсказанные суммы соответствующей базовой модели. Суммы фактических отгрузок на горизонте прогноза в расчёте не участвуют.

## Воспроизведение CSV

В дополнение к основным зависимостям требуется PyTorch: `python -m pip install -r requirements.txt "torch==2.15.0"`. Для CPU в Linux можно использовать CPU-сборку PyTorch. Команду запускают из корня проекта, когда CSV V3 и MAE25 для одного и того же момента уже созданы. SHA-256 ниже относятся к исходным локальным прогнозам команды. Если вы самостоятельно пересчитали входные файлы, сначала проверьте соответствие модели, сетки и момента прогноза; при другом текстовом формате CSV его SHA-256 может отличаться.

```bash
python scripts/make_mlp_share_submission.py \
  --train data/raw/train_solo_track.parquet --test data/raw/test_solo_track.parquet \
  --mae25-csv submissions/mae_share_mass25.csv \
  --mae25-sha256 a7e7f91e5e02ef6595bbd0dc49704086a46e228b69fd08e987085916a30ea5bd \
  --v3-csv submissions/v3_tweedie_h1_600.csv \
  --v3-sha256 b9974b280b64aa38e5ff50ae5e76999adce78967a5adadacd233cb75822e9769 \
  --forecast-origin '2025-11-01 10:30:00' \
  --output submissions/v3_totals_mlp_shares50_reproduced.csv
```

Маршруты и горизонты сопоставляются по ключам теста и `id`. Команда обучает только MLP, проверяет 8000 строк в финальном файле соревнования и записывает параметры расчёта в соседний файл метаданных. Для сохранения состояния обучения можно добавить `--checkpoint models/mlp.pt`.

## Результаты

На 14 датах разработки, 18–31 октября 2025, средняя WAPE снизилась с 0,316184 у V3 до 0,315679. Средний штраф за смещение остался 0,011753. Итог — 0,327433 против 0,327937; улучшение на 13 из 14 дат. [Все сравнения по датам](../results/v3_totals_mlp_shares50/development/folds.csv).

При полном повторном обучении на исходном train команда сборки создала побайтно тот же файл, что и первоначальный расчёт: SHA-256 `11466e7371a79a8fda5b22e0d65fba9e76d21da5d350800816f96ce7355edd69`. Это проверка воспроизводимости, а не публичного score.

Для повторной временной валидации можно явно перечислить даты. Модели обучаются заново на истории, заканчивающейся в заданные моменты:

```bash
python scripts/backtest_mlp_shares.py --train data/raw/train_solo_track.parquet \
  --origins '2025-10-18 10:30' '2025-10-19 10:30' \
  --output-dir results/reproduced_mlp_oct18_19
```
