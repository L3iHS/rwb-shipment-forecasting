# Исходные данные и происхождение файлов

Оригиналы получены от пользователя 06.11.2026 из материалов [соревнования WB Space](https://wbspace.wb.ru/competitions/kejs-chempionat). Файлы скопированы без изменения содержимого; SHA-256 исходников и копий совпал.

| Путь в репозитории | Исходное имя | Размер, байт |
|---|---|---:|
| `raw/train_solo_track.parquet` | `train_solo_track.parquet` | 94 465 651 |
| `raw/test_solo_track.parquet` | `test_solo_track.parquet` | 55 000 |
| `reference/sample_submission.csv` | `7d0fdad7-06fc-4bd3-9ab4-e4ef946a2b88.csv` | 186 712 |
| `reference/baseline.ipynb` | `baseline.ipynb` | 17 582 |

Контрольные суммы и исходные имена находятся в [manifest.json](manifest.json). CSV переименован в понятное имя `sample_submission.csv`; его байты сохранены.

По решению команды исходные датасеты включены в Git; материалы `reference/` (ноутбук и пример посылки организаторов) хранятся локально. `raw/` и `reference/` содержат неизменяемые оригиналы. Новые признаки сохраняем в `processed/`, собственные посылки — в `../submissions/`, обученные модели — в `../models/`. Генерируемые файлы этих трёх каталогов исключены из Git.

Описание колонок, временных границ и метрики: [docs/task.md](../docs/task.md).

## Повторная проверка

Из корня репозитория:

```bash
python scripts/profile_data.py
```

Скрипт проверяет SHA-256 четырёх оригиналов и контракт данных, затем сохраняет локальные отчёты в `.local/reports/data_audit/`. Данные не модифицирует, модель не обучает, файлы на платформу не отправляет.

## Baseline организаторов

`reference/baseline.ipynb` сохранён без изменений. В оригинале ожидается запуск из каталога с train/test, а CSV сохраняется в текущую директорию. Для экспериментов копируйте notebook в рабочий каталог и меняйте пути в копии; оригинал в `data/reference/` сохраняйте неизменным.

Для чтения train в pandas требуется около 333 МБ только под значения девяти колонок; временные операции и обучение потребуют дополнительной памяти.
