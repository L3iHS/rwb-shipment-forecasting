# Сохранённые прогнозы для воспроизведения

Эти файлы используются в [ноутбуке решения](../../ensemble_v3_weekly50.ipynb). Контрольные суммы, размеры и происхождение записаны в [manifest.json](manifest.json).

| Файл | Содержимое |
|---|---|
| `teammate_v3.csv` | Исходный конкурсный прогноз v3 из коммита `3b7394a0`, 8000 ID |
| `weekly.csv` | Проверенный конкурсный прогноз `weekly_v3_latent_half_shares`, 8000 ID |
| `development.npz` | Завершённые прогнозы v3 и недельной модели, известный таргет и ключи для 14 дат 18–31 октября 2025 |
| `control.npz` | Те же массивы для исторического контроля 27 сентября–3 октября 2025 |

В каждом NPZ: `truth`, `peer`, `weekly` размера «дата × 1000 маршрутов × 8 горизонтов», а также `origins`, `routes`, `horizon_steps`. Загрузка выполняется с `allow_pickle=False`.

На контроле множитель v3 был подобран только по предшествующим 14 дням; на разработке — по самим датам разработки. Подробности и различие CPU/CUDA приведены в ноутбуке и [методике](../../../docs/peer-v3-blend.md). Теперь опубликованные контрольные прогнозы позволяют пересчитывать метрики завершённого эксперимента; их результаты уже известны при разработке следующих вариантов.

Полное обучение компонентов описано по ссылкам в конце ноутбука. Обученные веса в этот комплект не входят.
